# ipam_allocation (Resource)

One CIDR allocated from a pool: the next free CIDR of `prefix_length`, or exactly `cidr`. The allocation ID is generated when it is created. Only `description` and `labels` update in place; every other change replaces the allocation. Destroy releases the CIDR.

## Changes and replacement

`description` and `labels` update in place. Changing `pool` or `prefix_length`, or setting a different `cidr`, replaces the allocation. Destroy releases the CIDR back to the pool.

Set exactly one of `prefix_length` (the next free CIDR of that size) or `cidr` (exactly that range). The `id` and, with `prefix_length`, the `cidr` are unknown until apply.

## Failed and uncertain creates

When Create fails before anything was written (pool exhausted, overlap, invalid CIDR, pool not found), nothing is saved to state. When the outcome is uncertain (a timeout, access denied after the timeout, a network error), the provider keeps the generated ID in state and Terraform marks the resource tainted. The next apply refreshes it: if the write never landed, the entry is dropped and a new allocation is made; if it did land, the tainted allocation is released and replaced. Either way, nothing leaks.

If Terraform itself is killed between the write and saving state, the allocation can leak. Find it with `ipam alloc list <pool>`, then import it or release it with `ipam alloc release <pool> <id>`.

## Example Usage

```terraform
# Copyright 2026 Appvia Ltd.
# SPDX-License-Identifier: MPL-2.0

# The next free /24 in a pool.
resource "ipam_allocation" "vnet" {
  pool          = "uks"
  prefix_length = 24
  description   = "Hub VNet"
  labels = {
    team = "network"
  }
}

# Exactly this CIDR (a reservation).
resource "ipam_allocation" "gateway" {
  pool = "uks"
  cidr = "10.1.255.0/24"
}

# Several allocations with count.
resource "ipam_allocation" "subnet" {
  count = 3

  pool          = "uks"
  prefix_length = 26
  description   = "subnet ${count.index}"
}

# One allocation per app with for_each.
resource "ipam_allocation" "app" {
  for_each = toset(["api", "web"])

  pool          = "uks"
  prefix_length = 24
  labels = {
    app = each.key
  }
}

# IPv6.
resource "ipam_allocation" "v6" {
  pool          = "platform-v6"
  prefix_length = 48
}

output "vnet_cidr" {
  value = ipam_allocation.vnet.cidr
}
```

## Schema

### Required

- `pool` (String) ID of the pool to allocate from.

### Optional

- `cidr` (String) The allocated CIDR. Set it to allocate exactly this canonical CIDR (a reservation); otherwise it is computed. Conflicts with `prefix_length`.
- `description` (String) Free-text description. Updated in place.
- `labels` (Map of String) Free-form labels, for example the owning team. Updated in place.
- `prefix_length` (Number) Allocate the next free CIDR of this prefix length. Conflicts with `cidr`.

### Read-Only

- `created_at` (String) When the allocation was created (RFC 3339).
- `id` (String) Allocation ID: a UUIDv7 generated when the allocation is created.

## Import

Import an allocation as `<pool>/<id>`. Import restores `prefix_length` or `cidr` from how the allocation was made, so the imported state matches the configuration that created it.

```shell
# Copyright 2026 Appvia Ltd.
# SPDX-License-Identifier: MPL-2.0

# Import an allocation as <pool>/<allocation id>.
terraform import ipam_allocation.vnet uks/018f22e2-1865-7be8-9f45-35d90607d0f7
```

With Terraform 1.12 or later you can also import by identity:

```terraform
# Copyright 2026 Appvia Ltd.
# SPDX-License-Identifier: MPL-2.0

import {
  to = ipam_allocation.vnet
  identity = {
    pool = "uks"
    id   = "018f22e2-1865-7be8-9f45-35d90607d0f7"
  }
}
```
